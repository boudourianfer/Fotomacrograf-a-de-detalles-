# Fotomacrografía-de-detalles-
Lo que vemos aquí es la punta de un bolígrafo, aumentada un par de veces en el fotograma original de 24×36. En cuanto a los colores del fondo, el amarillo y el azul corresponden a dos cuadernos y el rojo a un pequeño clip de los que llevan cubierta de plástico. 
Objetivo 
50 mm con fuelle automático. 
Exposición 
Automática, con un flash TTL.
